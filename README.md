# Seha PDF Service

خدمة مستقلة لتوليد PDF باستخدام Puppeteer على Render.

## الرابط
بعد النشر على Render استخدم:

/pdf?url=https://YOUR-INFINITYFREE-SITE/print_template.php?id=1

## ملاحظة مهمة
صفحة print_template.php يجب أن تكون قابلة للفتح من Render بدون تسجيل دخول، أو استخدم رابط آمن فيه token.
